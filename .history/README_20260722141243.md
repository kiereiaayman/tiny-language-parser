# Tiny Language Parser

A lexer and recursive-descent parser for the **TINY** language (as defined in *Compiler Construction: Principles and Practice*), built in C++ with a Qt-based GUI for visualizing the resulting Abstract Syntax Tree (AST). Developed as a project for a Compilers/Compiler Construction course.

## Overview

TINY is a small, educational programming language used to teach the fundamentals of lexical analysis and parsing. This project implements:

- **Lexer (Scanner):** Tokenizes TINY source code, identifying keywords, identifiers, numbers, operators, and comments while reporting lexical errors.
- **Parser:** A recursive-descent parser that checks the token stream against the TINY grammar and builds an Abstract Syntax Tree (AST), reporting syntax errors with line/context information.
- **GUI (Qt):** A desktop interface that lets you load or type TINY source code, run the scanner/parser, and view the generated AST in a readable, visual format instead of raw console output.

## Features

- Full lexical analysis of TINY source files (tokens, identifiers, reserved words, operators)
- Recursive-descent parsing of the TINY grammar (statements, expressions, control flow — `if`, `repeat`, assignments, `read`/`write`)
- AST construction and tree visualization
- Syntax/lexical error reporting
- Qt GUI for interactive input and visual output (no need to read raw terminal dumps)

## Getting Started

### Prerequisites

- A C++ compiler (GCC/Clang/MSVC)
- CMake (3.x or later)
- Qt (5 or 6 — matching whatever version `parser-GUI` targets)

### Build

```bash
git clone https://github.com/kiereiaayman/tiny-language-parser.git
cd tiny-language-parser
git checkout Dev
mkdir build && cd build
cmake ..
cmake --build .
```

### Run

Launch the built GUI executable, then either paste TINY source code into the input panel or load a `.tny` file, and run the scanner/parser to view the token stream and resulting AST.

## Example

```
{ Sample program in TINY language }
read x;
if 0 < x then
    fact := 1;
    repeat
        fact := fact * x;
        x := x - 1;
    until x = 0;
    write fact;
end
```

This project was built for a Compiler Construction course to demonstrate the front-end phases of a compiler: lexical analysis and syntax analysis, with the AST visualization added as a GUI extension on top of the core scanner/parser logic.
